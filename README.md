
# 📊 DataMoney Next

Projeto de Business Intelligence desenvolvido para analisar o comportamento financeiro de jovens utilizando Excel, Power BI e DAX.

## Tecnologias

- Excel
- Power BI
- DAX
- PowerPoint

## Objetivo

Transformar dados em insights por meio de dashboards e indicadores (KPIs), simulando um cenário de análise de dados aplicado à educação financeira.
