
# 📊 DataMoney Next

## Business Intelligence aplicado à Educação Financeira

O **DataMoney Next** é um projeto de Business Intelligence desenvolvido para analisar o comportamento financeiro de jovens entre 18 e 30 anos, utilizando dados simulados para representar um cenário de análise próximo ao ambiente corporativo.

O projeto percorre diferentes etapas de um fluxo de BI, desde a estruturação dos dados até a criação de dashboards e comunicação dos principais insights.

## 🎯 Objetivo

Transformar dados financeiros em informações visuais e indicadores que permitam identificar padrões de comportamento e apoiar a tomada de decisão.

## 🔎 Sobre o projeto

Foi construída uma base de dados fictícia com informações sobre:

- Idade
- Renda
- Gastos
- Economia
- Reserva financeira
- Uso de aplicativos financeiros
- Objetivos financeiros

A partir desses dados, foram desenvolvidos dashboards interativos no Power BI para explorar diferentes características do comportamento financeiro.

## 📊 Dashboards

O projeto apresenta análises relacionadas a:

- Renda e economia
- Economia por faixa etária
- Uso de aplicativos financeiros
- Objetivos financeiros
- Reserva de emergência
- Perfis com maior nível de endividamento

## 💡 Principais insights

A análise da base simulada permitiu identificar padrões como:

- Jovens que utilizam aplicativos financeiros apresentaram maior capacidade de economia.
- A média de economia aumenta conforme a faixa etária.
- Uma parcela reduzida dos participantes possui reserva de emergência.
- Parte dos perfis analisados apresenta situação de endividamento.

> Os resultados apresentados são baseados em uma base de dados fictícia criada exclusivamente para fins educacionais e de portfólio.

## 🛠️ Tecnologias utilizadas

- **Excel** — criação e organização da base de dados
- **Power BI** — desenvolvimento dos dashboards
- **DAX** — criação de medidas e indicadores
- **PowerPoint** — apresentação executiva
